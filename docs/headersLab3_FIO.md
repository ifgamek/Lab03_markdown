
## Лабораторная работа № 3 Markdown
#### Markdown — это облегчённый язык разметки текста. Простыми словами: это способ оформлять текст (заголовки, списки, ссылки, жирный шрифт) с помощью обычных символов, не отвлекаясь на сложный код.

#### Где применяется: Документация и README на GitHub, GitLab.Мессенджеры (Telegram, Discord, WhatsApp) — для выделения текста.Блоги и сайты (статические генераторы: Hugo, Jekyll).Заметки (Obsidian, Notion, Joplin).Форумы (Reddit, Stack Overflow).

#### Для чего нужен:Быстро писать структурированный текст без мышки.Легко читать даже в исходном виде (без рендеринга).Конвертировать в HTML, PDF, DOCX одной командой.
